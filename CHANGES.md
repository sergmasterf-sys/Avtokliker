# Изменения

1. FastPipeline: нажатия «Начать» и «Продолжить» теперь с проверкой.
   - Тап -> ждём, что кнопка исчезла (2 кадра подряд). Если нет, повтор: start через 0,8 с (после 4 тапов 1,6 с), continue через 0,7 с.
   - Цикл считается только после подтверждения «Начать».
   - Тап по continue только если кнопка видна 2 кадра подряд; новые кнопки запоминаются только после 2 одинаковых кадров.
   - Если continue не исчезает после 5 тапов, отпечаток удаляется как ложный (пауза 10 с).
   - В матче тапов нет; если снова виден start (не сработал тап или матч закончился), возврат в лобби.
2. AccessibilityWatchdog: проверка службы доступности каждые 4 с.
   - Уведомление с кнопкой «Открыть настройки», если служба отключилась.
   - Автоперезапуск службы (выкл/вкл), если выдано WRITE_SECURE_SETTINGS.
   - Выдать один раз: pm grant com.aistudio.autoclicker.app android.permission.WRITE_SECURE_SETTINGS
3. AndroidManifest: largeHeap="true", разрешение WRITE_SECURE_SETTINGS.

## Дополнительно (версия 2)

4. Служба доступности включается сама (если один раз выдан WRITE_SECURE_SETTINGS):
   - при каждом запуске приложения (Application.onCreate);
   - после перезагрузки устройства и после обновления приложения (BootReceiver);
   - в AccessibilityWatchdog: теперь включает службу и тогда, когда система убрала её из списка включённых (раньше только перезапускал «упавшую»).
5. «Ложные» точки continue (например, кнопка присесть в матче): если тап не убрал «кнопку», точка запоминается как ложная (до 20 точек, радиус 60 px) и больше не калибруется.
6. debug.keystore теперь лежит в репозитории (убран из .gitignore): сборки с GitHub подписываются одним и тем же ключом, обновление ставится поверх без удаления (иначе слетают служба доступности и разрешение).
   ВАЖНО: первый раз после этой версии старую установку нужно удалить (она подписана другим ключом), дальше — только обновление поверх.

## Выдать разрешение без ПК (один раз)
Настройки -> Для разработчиков -> Беспроводная отладка (нужен Wi-Fi) -> в LADB (или Shizuku + терминал) выполнить:
pm grant com.aistudio.autoclicker.app android.permission.WRITE_SECURE_SETTINGS
Разрешение сохраняется после перезагрузки и обновлений (пока приложение не удалено).
